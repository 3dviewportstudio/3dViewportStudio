2. What data is processed

This site has no user accounts and no advertising, and it does not store contact form data on any server. The form only drafts an email in your own mail app; nothing is sent until you send it. Google Analytics is used only if you accept measurement cookies.

  • Browsing data, only if you accept measurement cookies: pages viewed, visit duration, device type, approximate location and cookie identifiers, collected by Google Analytics. IP addresses are not stored.
