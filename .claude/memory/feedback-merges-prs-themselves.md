Open the pull request and give the user the link; don't try to merge it.

**Why:** In Oct 2026 a merge attempted by the agent was blocked by the session's permission checks; merging is left to the user on GitHub.

**How to apply:** After pushing work, open the PR when asked and stop there unless the user has explicitly allowed merging in that session.
